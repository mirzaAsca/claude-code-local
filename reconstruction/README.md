# Reconstruction Source-of-Truth Files

This directory contains the public, hand-edited inputs used by the reconstruction compatibility layer.

## Edit Policy

- Hand-edit only [`features.json`](/Users/mirzaasceric/Desktop/claude-code-local/reconstruction/features.json) and [`macros.json`](/Users/mirzaasceric/Desktop/claude-code-local/reconstruction/macros.json).
- Do not hand-edit generated outputs in `reconstruction/generated/`.
- After editing [`macros.json`](/Users/mirzaasceric/Desktop/claude-code-local/reconstruction/macros.json), run `bun run reconstruct:macros`.
- Validate both files with `bun run reconstruct:verify` (this now enforces strict schema checks and unknown-key failures).
- Do not hand-edit `reconstruction/manifest.json` — it is generated by `bun run reconstruct:hydrate`.

## Hydration

Run `bun run reconstruct:hydrate` to:

1. Scan for unresolved imports
2. Apply recovery sources from `reconstruction/sources/`
3. Generate stubs for remaining unresolved modules
4. Write `reconstruction/manifest.json` with per-module tracking
5. Write `reconstruction/reports/hydration-delta.json` with pre/post comparison

## Directory Layout

| Path | Purpose | Editable? |
| --- | --- | --- |
| `features.json` | Feature flag source of truth | Yes |
| `macros.json` | Macro constant source of truth | Yes |
| `manifest.json` | Per-module recovery status | No (generated) |
| `generated/` | Build-time artifacts (macros.ts, etc.) | No (generated) |
| `sources/` | Manually placed recovery files | Yes |
| `reports/` | Scan and hydration reports | No (generated) |
